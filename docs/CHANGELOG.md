# Changelog — TrustBoundary AI

## v1.6.0 — October 10, 2026 (local hardening release)

- NFKC, zero-width and selected Cyrillic/Greek confusables; bounded spaced-attack-token joining.
- Recursive Base64 (depth 2), ROT13 with indicator, URL-unquote and hex decoding candidate inspection.
- Educational reporting cues mask quoted examples only, without exempting an instruction that orders the agent to execute the quote.
- Weighted signal groups provide additional limited evidence; not an unseen semantic generalization breakthrough.
- DOCX body/header/footer/comment/hidden-run ingestion; Python/JS source and comments.
- One centrally declared release version, extended regression tests, template-family GroupKFold report and 50-benign-case trial.
- Pinned external evaluation script; unable to retrieve and run external dataset in offline build environment. Live OpenAI path unverified without a fresh secret.
