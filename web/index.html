How privacy and fallback work

Your key stays in this browser tab's memory. It is not written to browser storage, server storage, a database, a URL, analytics, GitHub or audit traces. Closing or refreshing the tab clears it.

When OpenAI mode is enabled, the selected untrusted text and the key travel over the same-origin request to this FastAPI server. The server calls OpenAI with the key and returns only the classification; the original key is never returned. Your OpenAI account may incur API charges.

Always available: selecting Offline runs the local rule/ML detector. If the hosted model times out or fails, the scan falls back to offline detection and shows that fallback in the classifier label. The separate deterministic tool gate stays enforced.

Security: only enter a newly generated, private key on a trusted HTTPS installation. This hackathon demonstrator is not hardened for open Internet deployment; authentication and rate limiting are still required. Never share an API key in chat or commit it to GitHub.
