# Release status (v1.7.0)

Local source, offline test suite, revised presentation and reproducible evaluator have been prepared and tested. Read the repository README for accurate numerical results; accuracy on feedback-informed cases is not an independent benchmark.

## Supported
- Offline rules, structural signals and local statistical ML.
- Optional strict-schema OpenAI semantic judge and **optional real-model proposal simulation**, requiring a private personal key and provider access. Live performance has not been independently measured.
- Policy gate rejects unauthorized synthetic payment/email/secret operations independently from detection.
- Supported text, DOCX and optional OCR inputs; experimental single-process cross-turn state.

## Unverified
- Real OpenAI call and model-tool attack success rate.
- Public external dataset numeric benchmark.
- Independently sealed holdout evaluation.
- Publicly hosted authenticated HTTPS demo and signed-out playback.
- Final narrated **live screen recording in the participant's own voice**. Earlier video is an illustrative screenshot walkthrough.
- Competition submission and receipt; not included in this development workflow.

Do not interpret this prototype as a production security control.
